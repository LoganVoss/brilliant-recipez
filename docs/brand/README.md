# Brand artwork

Created with the built-in image generation tool for Brilliant! Recipez. The mark combines a lightbulb, brain folds, a citrus lightning bolt, and a fork-like base. The original generated PNG is included here; the app icon is resized to 1024 × 1024.

Prompt: “A simple, memorable fusion of a lightbulb and brain, with a subtle food cue and tiny lightning bolt. One bold warm ivory lightbulb silhouette; inside it a few dark forest-green rounded brain folds with a tiny citrus-yellow lightning bolt. The bulb base subtly resembles a small three-tine fork. One unified mark that reads clearly at app-icon size. Flat geometric vector-like design. Full-bleed deep forest-green square background, generous safe padding, no text, no mockup.”
